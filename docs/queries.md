## 1. CLAIMS_QUERY (core.detectors.pressure)

Pressure: claims as of T (spec 7.1)

```cypher
MATCH (a:Actor)-[:ASSERTED]->(c:Claim) WHERE c.kind IN $kinds AND c.at <= $T AND c.at > $start RETURN a.hid AS hid, c.id AS claim_id, c.kind AS kind, c.at AS at ORDER BY at, claim_id
```

MATCH (a:Actor)-[:ASSERTED]->(c:Claim {kind: 'VOUCH'}) WHERE c.at <= $T RETURN a.hid AS hid, c.id AS claim_id, c.target_hid AS target, c.at AS at ORDER BY at, claim_id

## 3. SHARES_QUERY (core.detectors.vouch)

MATCH (a:Actor)-[s:SHARES]->(b:Actor) WHERE a.hid IN $hids AND b.hid IN $hids RETURN a.hid AS a, b.hid AS b, s.signal AS signal ORDER BY a, b, signal LIMIT 1000
```

## 4. GRANTS_QUERY (core.detectors.rush)

Rush: grants as of T (spec 7.1)

MATCH (a:Actor)-[e:GRANTED]->(p:Privilege {kind: $kind}) WHERE (e.at IS NULL OR e.at <= $T) RETURN a.hid AS hid, e.at AS at ORDER BY hid, at
```

## 5. FIRST_ACTION_QUERY (core.detectors.rush)

Rush: first action by a keeper (spec 7.1)

```cypher
MATCH (a:Actor)-[d:DID]->(x:Action) WHERE a.hid IN $hids AND (d.at IS NULL OR d.at <= $T) RETURN a.hid AS hid, min(d.at) AS first_at, count(d) AS n, count(d.at) AS n_dated LIMIT 1000
```

## 6. HISTORY_QUERY (core.detectors.low_history)

Low history: prior actions for an actor

```cypher
MATCH (a:Actor) WHERE a.hid IN $hids AND (a.first_seen_in_org IS NULL OR a.first_seen_in_org <= $T) OPTIONAL MATCH (a)-[d:DID]->(:Action) WHERE d.at <= $T WITH a, count(d) AS actions, min(d.at) AS first_did RETURN a.hid AS hid, a.first_seen_in_org AS seen, actions, first_did ORDER BY hid LIMIT 1000
```

## 7. PATH_QUERY (core.takeover.cost)

Takeover cost: SPpaths from the outsider (spec 2.2)

```cypher
MATCH (s:Flow {id: 'OUTSIDER'}), (t:Privilege {kind: $kind}) CALL algo.SPpaths({sourceNode: s, targetNode: t, relTypes: ['OUTSIDER_ENTRY', 'CAN_GRANT', 'GRANTED'], weightProp: 'approvals'}) YIELD path, pathWeight RETURN pathWeight, [n IN nodes(path) | coalesce(n.id, n.hid, 'PRIV:' + n.kind)] AS ids ORDER BY pathWeight LIMIT 1
```

## 8. ENTRY_QUERY (core.takeover.cost)

Takeover cost: entry points (spec 2.2)

```cypher
MERGE (o:Flow {id: 'OUTSIDER'}) WITH o MATCH (a:Actor) MERGE (o)-[e:OUTSIDER_ENTRY]->(a) SET e.approvals = $entry
```

## 9. PROJECTION (core.takeover.guardians)

Guardians: flow network projection (spec 2.2, 7.4)

```cypher

MATCH (k:Actor)-[:CAN_GRANT]->(p:Privilege {kind:$privilege})
MERGE (ki:Flow {id: k.hid + ':in'})  MERGE (ko:Flow {id: k.hid + ':out'})
MERGE (ki)-[:CAP {c: 1}]->(ko)
MERGE (src:Flow {id:'OUTSIDER'})     MERGE (dst:Flow {id:'PRIV:' + $privilege})
MERGE (src)-[:CAP {c: 1000000}]->(ki)
MERGE (ko)-[:CAP {c: 1000000}]->(dst);
```

## 10. GUARDIANS_QUERY (core.takeover.guardians)

Guardians: min-cut query, maxFlow (spec 7.4)

```cypher

MATCH (s:Flow {id:'OUTSIDER'}), (t:Flow {id:'PRIV:' + $privilege})
CALL algo.maxFlow({sourceNodes:[s], targetNodes:[t], capacityProperty:'c', relationshipTypes:['CAP']})
YIELD maxFlow
RETURN maxFlow AS guardians
```

## 11. GAP_QUERY (packs.oss.ecosystem.gaps)

Visibility gaps, UNREACHABLE / UNNOTICED (spec 7.5)

```cypher
MATCH (d:Decision {ref:$decision})-[:MADE_IN]->(dp:Place)<-[:WATCHES]-(r:Role)
MATCH (d)-[:CONCERNS]->(i:Identity)-[:SAME_AS*0..2]-(j:Identity)
MATCH (j)-[:EMITTED]->(s:Signal)-[:RECORDED_IN]->(sp:Place)
WHERE s.at < d.at
OPTIONAL MATCH (r)-[w:WATCHES]->(sp) WHERE w.since < s.at
OPTIONAL MATCH (d)-[ref:REFERENCES]->(s)
RETURN s.kind, s.ref, sp.ref AS seen_in,
       CASE WHEN w IS NULL THEN 'UNREACHABLE'
            WHEN ref IS NULL THEN 'UNNOTICED' END AS gap
LIMIT 1000
```

## 12. Q_ACTORS (redteam.load_tallowdate)

Synthetic tallowdate load: actors (spec 3.5)

```cypher
UNWIND $rows AS r
MERGE (a:Actor {hid: r.hid})
  SET a.kind = 'human', a.first_seen_in_org = r.first_seen, a.synthetic = true,
      a.planted = r.planted, a.campaign_id = r.campaign_id, a.name = r.name
```

## 13. Q_ACTIONS (redteam.load_tallowdate)

Synthetic tallowdate load: actions (spec 3.5)

```cypher
UNWIND $rows AS r
MERGE (a:Actor {hid: r.hid})
MERGE (c:Action {ref: r.ref})
  SET c.kind = r.kind, c.at = r.at, c.case = $case, c.synthetic = true,
      c.planted = r.planted, c.campaign_id = r.campaign_id
MERGE (a)-[d:DID]->(c)
  SET d.at = r.at, d.synthetic = true
```
